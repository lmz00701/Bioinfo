TCGA-LIHC 数据下载教程

手把手教你从 UCSC Xena 下载肝癌（LIHC）的 HTSeq-FPKM 表达矩阵和临床表型数据

⏱ 预计耗时：5 分钟 | 💻 适合：R / Python 用户

📋 详细下载步骤

按照以下 5 个步骤，一步步完成数据下载

1

打开 UCSC Xena 网站

在浏览器中访问 UCSC Xena 官网，点击 "Launch Xena" 进入数据浏览器。

🌐 打开 https://xena.ucsc.edu/ → 点击 Launch Xena
# 直接在浏览器地址栏输入或直接点击上方按钮 https://xena.ucsc.edu/
2

点击左上角 "DATA SETS"

进入主界面后，点击左上角的 DATA SETS 标签，进入数据集搜索页面。

📂 点击左上角 DATA SETS
3

搜索并找到 LIHC

在列表中找到并点击 TCGA Liver Cancer (LIHC)。

4

找到并下载 HTSeq-FPKM

进入 LIHC 页面后，向下滚动找到 gene expression RNAseq 模块，点击其中的 HTSeq-FPKM 并进行下载。

不要下载UQ版本，本次不要UQ版本；后续扩展实验用STAR - Counts ,同样方式下载

📄 下载文件 1：HTSeq-FPKM

文件名示例：TCGA-LIHC.htseq_fpkm.tsv.gz

  • 内容：基因表达矩阵（行=基因，列=样本）
  • 格式：已做 log2(FPKM+1) 转换
  • 样本数：约 424 个
5

找到并下载 phenotype（临床表型）

继续在同页面向下滚动，找到 phenotype 模块，点击并进行下载。

📋 下载文件 2：Phenotype

文件名示例：TCGA-LIHC.GDC_phenotype.tsv.gz

  • 内容：临床表型数据（年龄、性别、分期、 grade 等）
  • 样本数：约 439 个
  • 📌 建议：如果做生存分析，也顺便下载 survival.tsv.gz

📦 下载的文件说明

了解你拿到的每个文件长什么样

📄 TCGA-LIHC.htseq_fpkm.tsv.gz

💠 基因表达矩阵（HTSeq-FPKM）

属性说明
行（Row）基因 Ensembl ID（如 ENSG00000000003.14）
列（Column）样本 barcode（如 TCGA-2H-A9GF-01A）
数值log2(FPKM + 1) 转换后的值
样本数约 424 个（含肿瘤 + 正常）

📋 TCGA-LIHC.GDC_phenotype.tsv.gz

🩺 临床表型数据（Phenotype）

属性说明
行（Row）样本（第一列为 sample_id）
列（Column）临床变量
常见字段age_at_diagnosis, gender, stage, grade, sample_type 等
样本数约 439 个
⚠️ 注意事项
  • 样本数不一致是正常的：表达矩阵约 424 个样本，临床表型约 439 个，因为部分样本没有表达数据。
  • 合并时以表达矩阵为准：用 merge 或 inner_join 按样本 ID 对齐即可，只会保留两边都有的样本。
  • barcode 第 14-15 位：01 = 肿瘤组织，11 = 正常组织，02 = 转移的肿瘤。
  • FPKM 不适合直接做差异分析：如果你需要做 DESeq2/edgeR 的差异表达，建议下载上面的 STAR - Counts 而不是 FPKM。

📝 下载后如何用 R / Python 读取

拿到文件后，快速查看和合并数据

R

R 读取代码

将下载的两个文件放在同一个文件夹，运行以下代码：

# 1. 安装必要的包（第一次运行时） install.packages(c("data.table", "tidyverse")) # 2. 加载包 library(data.table) library(tidyverse) # 3. 设置文件路径（改成你实际的路径） fpkm_file <- "TCGA-LIHC.htseq_fpkm.tsv" pheno_file <- "TCGA-LIHC.GDC_phenotype.tsv" # 4. 读取文件 expr <- fread(fpkm_file) # 表达矩阵 pheno <- fread(pheno_file) # 临床表型 # 5. 查看数据结构 dim(expr) # 查看维度 dim(pheno) # 查看维度 colnames(expr)[1:5] # 查看前5个列名 colnames(pheno)[1:5] # 查看前5个列名 head(expr, 3) # 查看表达矩阵前3行 head(pheno, 3) # 查看临床表型前3行 # 6. 只保留肿瘤样本（barcode 第14-15位是 01） # 样本ID格式：TCGA-2H-A9GF-01A，第14-15位是 -01- tumor_samples <- pheno$sample_id %>% str_subset("-01-") # 只保留肿瘤 # 7. 合并表达矩阵和临床表型（按样本ID） # 先把表达矩阵转置，让样本变成行 expr_t <- expr %>% column_to_rownames("gene_id") %>% # 第一行是基因ID t() %>% # 转置 as.data.frame() %>% rownames_to_column("sample_id") # 样本ID列 merged <- inner_join(expr_t, pheno, by = "sample_id") # 或者更简单的方法： merged <- pheno %>% inner_join(t(expr[, -1]), by = "row.names") %>% column_to_rownames("row.names") # 8. 保存合并后的数据 write.csv(merged, "TCGA-LIHC_merged.csv", row.names = FALSE)
Python

Python 读取代码

将下载的两个文件放在同一个文件夹，运行以下代码：

# 1. 安装必要的库（第一次运行时） # pip install pandas # 2. 读取文件 import pandas as pd fpkm_file = "TCGA-LIHC.htseq_fpkm.tsv" pheno_file = "TCGA-LIHC.GDC_phenotype.tsv" expr = pd.read_csv(fpkm_file, sep='\\t', index_col=0) # 表达矩阵 pheno = pd.read_csv(pheno_file, sep='\\t', index_col=0) # 临床表型 # 3. 查看数据结构 print("Expression shape:", expr.shape) # (基因数, 样本数) print("Phenotype shape:", pheno.shape) # (样本数, 临床变量数) print(expr.head()) print(pheno.head()) # 4. 只保留肿瘤样本 # 样本ID格式：TCGA-2H-A9GF-01A，第14-15位是 -01- tumor_mask = pheno.index.str.contains(r"-01-") pheno_tumor = pheno.loc[tumor_mask] # 5. 合并（按样本ID） # 表达矩阵的行是基因，需要转置让样本变成行 expr_t = expr.T # 转置 expr_t.index.name = 'sample_id' merged = pheno.join(expr_t, how='inner') # 或者只合并肿瘤样本： merged_tumor = pheno_tumor.join(expr_t, how='inner') # 6. 保存 merged_tumor.to_csv("TCGA-LIHC_merged_tumor.csv")

🔗 不想点网页？直接用命令下载

如果你有服务器或 Mac/Linux 终端，可以直接用 wget 下载，一步到位：

# HTSeq-FPKM 表达矩阵 wget https://gdc.xenahubs.net/download/TCGA-LIHC/Xena_Matrices/TCGA-LIHC.htseq_fpkm.tsv.gz # 临床表型 phenotype wget https://gdc.xenahubs.net/download/TCGA-LIHC/Xena_Matrices/TCGA-LIHC.GDC_phenotype.tsv.gz # 生存数据（做KM曲线或Cox回归时用到，可选） wget https://gdc.xenahubs.net/download/TCGA-LIHC/Xena_Matrices/TCGA-LIHC.survival.tsv.gz # 解压 gunzip TCGA-LIHC.htseq_fpkm.tsv.gz gunzip TCGA-LIHC.GDC_phenotype.tsv.gz
